# claude-skills

Claude Code plugins and skills by [the-rusty-shackleford](https://github.com/the-rusty-shackleford).

## Plugins

| Plugin | What it does |
| --- | --- |
| [navigator](navigator) | Rubber duck on steroids. Claude becomes a Socratic pair-programming navigator that never writes your code: you drive, it questions, reviews, explains, and pokes holes. |

## Install

In Claude Code:

```
/plugin install navigator --marketplace the-rusty-shackleford/claude-skills
```

On older Claude Code versions, add the marketplace first:

```
/plugin marketplace add the-rusty-shackleford/claude-skills
/plugin install navigator@rusty-shackleford
```

Each plugin's README covers using its skill on its own, without the plugin.
